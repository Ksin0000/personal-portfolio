# [Ksin's portfolio](https://personal-portfolio-azg.pages.dev/background)

React + Vite 製の個人向けポートフォリオサイト。p5.js のアニメーション背景、shadcn/ui（Radix UI）を使った UI コンポーネント、React Router によるページ遷移で構成されています。

## 技術スタック
- React / TypeScript / Vite
- Tailwind CSS + shadcn/ui
- p5.js によるカスタム背景
- React Router / React Router DOM

## セットアップ
1. Node.jsと pnpm を用意
2. 依存関係をインストールします。
   ```bash
   pnpm install
   ```

## 開発フロー
- 開発サーバー
  ```bash
  pnpm dev
  ```
- ビルド
  ```bash
  pnpm build
  ```
